# La ruleta del cambio

Trivia educativa de 10 preguntas por partida sobre menopausia y andropausia.

## Ejecutar localmente

Requiere Node.js. Desde esta carpeta:

```powershell
node server.js
```

Luego abrir `http://127.0.0.1:4173/`.

## Contenido publicado

- Interfaz HTML, CSS y JavaScript.
- Banco editorial de 60 preguntas.
- Sonido de celebración y su atribución.
- Servidor local sin dependencias externas.

El contenido educativo no reemplaza una consulta médica.
